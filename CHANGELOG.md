# Changelog

## 1.0.0 — Android

- Native offline Android interface with exact black and red palette.
- Fedora-compatible encrypted vault protocol and ZIP/TAR.GZ/TAR archive handling.
- Notes with auto-save, file/folder storage, encrypted logs, trash and batch selection.
- Authenticated file import/export, encrypted and plaintext backup options, integrity checks.
- GitHub Actions to run compatibility tests and build a debug APK.
